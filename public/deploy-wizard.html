Encryption

API keys and secrets are encrypted at rest using AES-256-GCM. This requires the SETTINGS_ENCRYPTION_KEY environment variable.

How to fix:

  1. Generate a key: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
  2. Add to your .env file: SETTINGS_ENCRYPTION_KEY=<your-64-char-hex>
  3. Restart the server
