  • All features enabled by default

Multi-Tenant

Host multiple independent sites from one server. Each tenant gets its own content, settings, and subdomain.

  • Subdomain routing (e.g. tenant.yourdomain.com)
  • Per-tenant billing & API keys (BYOK)
  • Platform admin dashboard
Multi-tenant requires additional configuration After setup, you'll need to set TENANT_BASE_DOMAIN in your .env file for subdomain routing (e.g. TENANT_BASE_DOMAIN=yourdomain.com).
